# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this
repository. Do not open a public issue or pull request for a suspected
vulnerability.

Include the affected component, reproduction steps, impact, and any proposed
mitigation. Do not include production credentials, personal information,
financial records, national-identification data, database contents, signed
links, or private infrastructure identifiers. Maintainers may ask for a safer
way to exchange sensitive evidence.

## Supported version

Only the current production revision on the default branch receives security
updates. Historical commits and third-party deployments are unsupported.

## Operational security

Public source does not grant access to the hosted OURMU service or its data.
Production incidents, account-access requests, and privacy requests must use
the contact channel published by the hosted service, not GitHub issues.
